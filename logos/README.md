# Logos Folder

You can upload your logo images directly into this folder.

### 1. Top Logo (Sidebar Header)
- File name: `csrbox-logo.png` (or `csrbox-logo.svg`)
- Used for the brand header at the top of the sidebar.

### 2. Footer Logos (7 Initiative Logos)
Place your logo images here using the following filenames (PNG or SVG format):
1. `csrbox.png` (or `csrbox.svg`) — CSRBOX
2. `bharat-cares.png` (or `bharat-cares.svg`) — Bharat Cares
3. `impact-practice.png` (or `impact-practice.svg`) — Impact Practice
4. `indigive.png` (or `indigive.svg`) — IndiGive Foundation
5. `godavari.png` (or `godavari.svg`) — The Godavari Initiative
6. `one-purpose.png` (or `one-purpose.svg`) — One Purpose
7. `scholars-box.png` (or `scholars-box.svg`) — Scholars Box

When you upload any `.png` file with these names, the dashboard will automatically use your uploaded image!
